📖 New to This? Start Here

This tool requires a few programs to be installed on your computer. If you've never used a terminal or command line before, don't worry — here's what you need and how to get it.

🐍 What is Python and how do I install it?

Python is a programming language that this tool uses behind the scenes. You don't need to write any code — you just need it installed.

  1. Go to python.org/downloads
  2. Click the big yellow "Download Python 3.x" button
  3. Run the installer
  4. Important (Windows): Check the box that says "Add Python to PATH" before clicking Install
  5. Important (Mac): After installing, open the Applications/Python 3.x folder and double-click "Install Certificates.command"

To verify: open Terminal (Mac) or Command Prompt (Windows) and type python3 --version. You should see something like Python 3.12.x.

📦 What is pip?

pip is Python's package installer — it downloads add-on libraries that this tool needs. It comes bundled with Python, so if Python is installed correctly, pip should already work.

If the check above says pip is missing, try running: python3 -m ensurepip --upgrade

🟢 What is Node.js and how do I install it?

Node.js is a tool that runs the final course website locally on your computer so you can preview it in a browser.

  1. Go to nodejs.org/download
  2. Download the LTS version (recommended for most users)
  3. Run the installer with all default options

This also installs npm (Node Package Manager) automatically.

To verify: open a new terminal and type node --version. You should see something like v20.x.x.

🔑 Where do I get a Canvas API Token?

A Canvas API Token lets this tool securely download your course content. Here's how to get one:

  1. Log into your institution's Canvas (e.g. yourschool.instructure.com)
  2. Click your profile picture (top-left) → Account
  3. Click Settings
  4. Scroll down to "Approved Integrations"
  5. Click "+ New Access Token"
  6. Name it something like "Course Builder" and click Generate Token
  7. Copy the token immediately — you won't be able to see it again!

Paste this token on the Configuration page.

🤖 What AI provider should I use?

This tool uses AI to evaluate and enhance your course content. You need access to at least one AI provider:

  • NebulaONE — If your institution provides this, it's the easiest option. Ask your IT department or AI portal for the API key and base URL.
  • Anthropic (Claude) — Sign up at console.anthropic.com and create an API key. Requires a paid account.
  • OpenAI (GPT) — Sign up at platform.openai.com and create an API key. Requires a paid account.
  • Google Gemini — Get a key from Google AI Studio. Has a free tier.

Enter your chosen provider's key on the Configuration page, then select it when you run the pipeline.

What This Tool Does

1
Export from Canvas
Downloads your course content (pages, assignments, quizzes, discussions) using the Canvas API.
2
Evaluate AI Readiness
Each piece of content is scored across 8 dimensions: Bloom's level, cheating vulnerability, authenticity, pedagogical quality, and more.
3
AI Enhancement
Content is rewritten using the evaluation scores — adding learning objectives, rubrics, and AI-resilient design where needed.
4
Build & Launch
A local HAX website is built and launched so you can review the enhanced course in your browser.
