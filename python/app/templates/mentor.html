1. Course source (optional for a new course)

Large exports upload directly to private Vercel storage in bounded parts. You do not need Python or a local helper. The original cloud upload is deleted only after the prepared result is saved and validated; your computer's original is unchanged.

Is your export 2 GB or media-heavy?

Use the local preparation tool. It reads text/metadata without inflating bulk media and records what was excluded. Your original remains untouched. Upload the resulting compact .haxcourse package here.

python3 python/prepare_course.py "/path/course.imscc" --output "/path/course.haxcourse"

This is a review package, not a complete backup. Videos/images omitted locally are not analyzed or rebuilt unless provided separately in supported form.

Or connect to Canvas using this local app's API configuration

Acquires content only; it does not start analysis or bypass the mentoring checkpoints. Configure the local Canvas URL/token first. This legacy local configuration is not a hosted multi-user credential store.
